# ATTD.vn Engineering Standards

This folder defines the engineering standards for ATTD.vn source code.

## Scope

These standards apply to:

- Next.js App Router routes.
- API routes.
- Prisma schema and migrations.
- Shared domain logic.
- Validation.
- Permissions.
- Error handling.
- Logging.
- Testing.
- Deployment.

CMS/Admin UI standards live in [docs/cms-design-system](../cms-design-system). Public frontend UX is separate, but public frontend implementation still follows these engineering standards.
