# `src/lib/authority`

Shared source-code helpers for architecture authority may live here when future sprints need executable checks, constants, or utilities that support `docs/authority`.

Do place here:

- Authority metadata used across the app.
- Lightweight helpers that enforce documented architecture rules.
- Cross-module constants tied to authority decisions.

Do not place here:

- Business module logic.
- CMS/Admin UI components.
- Public frontend components.
- Documentation that belongs under `docs/authority`.
