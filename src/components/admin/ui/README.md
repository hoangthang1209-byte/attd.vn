# `src/components/admin/ui`

Reusable CMS/Admin UI primitives belong here.

Do place here:

- Admin buttons, inputs, selects, textareas, badges, cards, tables, toolbars, drawers, modals, tabs, toasts, and state components.
- Components that are reusable across multiple admin modules.
- Accessible primitives that follow `docs/cms-design-system`.

Do not place here:

- Public frontend components.
- Module-specific business logic.
- One-off admin components that belong under `src/components/admin/[module]`.
- Data fetching that belongs in routes, services, or features.
