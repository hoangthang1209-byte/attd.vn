# `src/components/admin/layout`

Reusable CMS/Admin layout components belong here.

Do place here:

- Admin shell, sidebar, header, breadcrumbs, page headers, content wrappers, and split-view layouts.
- Shared layout components that preserve consistent admin navigation and structure.

Do not place here:

- Public frontend layouts.
- Module-specific forms or tables.
- Business rules, validation logic, or permission enforcement.
- Route handlers or API helpers.
